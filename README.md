# แผนที่น้ำท่วม — นิคมอุตสาหกรรมอมตะซิตี้ ชลบุรี และพื้นที่โดยรอบ

แผนที่แจ้งจุดน้ำท่วมและขอความช่วยเหลือจากประชาชน ทุกรายการจะแสดงต่อสาธารณะหลังจาก **ผู้ดูแล (admin) ยืนยัน** แล้วเท่านั้น

- **🌊 แจ้งน้ำท่วม**: ปักหมุดจุดเดียว หรือ **วาดเส้นทางถนนที่น้ำท่วม** (แตะทีละจุดตามถนน ลากจุดเพื่อปรับ) เลือกระดับน้ำ แนบรูปได้
- **admin แก้ไขได้ทุกรายการ**: กด ✎ แก้ไข หรือแตะจุดบนแผนที่หน้า admin เพื่อย้ายจุด แก้เส้นทาง เปลี่ยนระดับน้ำ แก้ข้อความ ปิดรายงาน หรือเอาออกจากแผนที่
- **🏞 ระดับน้ำแม่น้ำบางปะกง**: สถานีบางปะกง (หมุดบนแผนที่ + กราฟ 3 วันเทียบตลิ่ง) และสถานีต้นน้ำ บางน้ำเปรี้ยว/ปราจีนบุรี/ศรีมหาโพธิ พร้อมเตือนเมื่อล้นตลิ่ง (ข้อมูลคลังข้อมูลน้ำแห่งชาติ ThaiWater สสน.)
- **🌊 ระดับน้ำทะเลขึ้นลง** (หน้าปากแม่น้ำบางปะกง): เวลาน้ำขึ้น/ลง กราฟ 48 ชม. และเตือนเมื่อฝนหนักตรงกับช่วงน้ำทะเลขึ้นสูง (ข้อมูลแบบจำลอง Open-Meteo Marine ไม่ใช่ตารางน้ำทางการ)
- **📡 เรดาร์ฝนบนแผนที่**: เปิด/ปิดได้ แสดงกลุ่มฝนล่าสุดและเล่นย้อนหลัง 2 ชม. (RainViewer ใช้ฟรีสำหรับงานส่วนตัว/การศึกษา)
- **🌧 โอกาสฝนตก**: ป้ายบอกโอกาสฝน 3 ชม. ข้างหน้า กดดูกราฟรายชั่วโมง 24 ชม. และแผนที่ฝนจาก Windy (พยากรณ์จาก Open-Meteo ใช้ฟรีสำหรับงานไม่แสวงหากำไร)
- **🔍 ค้นหาชื่อโรงงาน** (ไทย/อังกฤษ — พิมพ์อังกฤษได้แม้ชื่อในระบบเป็นภาษาไทย เช่น Toyota → โตโยต้า) แล้วแจ้งน้ำท่วมหรือขอความช่วยเหลือที่โรงงานนั้นได้ทันที รายชื่อตั้งต้นจาก OpenStreetMap และ admin เพิ่มเองได้ในแท็บ 🏭 โรงงาน หรือนำเข้าไฟล์ CSV (`name, name_en, lat, lng`)
- **สีระดับน้ำ**: เหลือง → ส้ม → แดง → ม่วง (ยิ่งเข้มยิ่งอันตราย จุดใหญ่ขึ้นตามความลึก)
- **🆘 ขอความช่วยเหลือ**: ปักหมุด เลือกสิ่งที่ต้องการ (ติดอยู่/อพยพ, ผู้ป่วย, ผู้สูงอายุ/เด็ก, อาหาร) จำนวนคน และเบอร์ติดต่อ ซึ่ง **เห็นเฉพาะเจ้าหน้าที่** มีปุ่มโทรเบอร์ฉุกเฉิน 1669 / 1784 / 199

พื้นที่ให้บริการ: อมตะซิตี้ ชลบุรี, พานทอง, หนองตำลึง, ดอนหัวฬ่อ, คลองตำหรุ ถึงปากแม่น้ำบางปะกง (ประมาณ 33 × 15 กม.)

## ลองใช้ทันที (โหมดทดลอง ไม่ต้องมีเซิร์ฟเวอร์)

```bash
python3 tools/serve.py 8010
```

- หน้าสาธารณะ: http://localhost:8010
- หน้าผู้ดูแล: http://localhost:8010/admin.html (โหมดทดลอง ใส่อีเมล/รหัสอะไรก็ได้)

โหมดทดลองเก็บข้อมูลไว้ในเบราว์เซอร์นี้เท่านั้น เปิดสองแท็บ (สาธารณะ + ผู้ดูแล) แล้วจะเห็นข้อมูลอัปเดตข้ามแท็บทันที

## ใช้งานจริงกับ Supabase

1. สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com) (แนะนำ region สิงคโปร์)
2. **SQL Editor** → วางไฟล์ `supabase/migrations/0001_init.sql` แล้วกด Run
   (สร้างตาราง, กติกาความปลอดภัย RLS, ที่เก็บรูป `flood-photos`, ตรวจพื้นที่ให้บริการ)
3. **Authentication → Sign In / Providers**
   - เปิด **Allow anonymous sign-ins** (ผู้แจ้งไม่ต้องสมัครสมาชิก)
   - **Allow new users to sign up ต้องเปิดไว้** ไม่อย่างนั้น anonymous sign-in จะใช้ไม่ได้ (คนที่สมัครด้วยอีเมลได้สิทธิ์เท่าผู้แจ้งทั่วไป ไม่ใช่ admin)
4. (แนะนำ) กันบอท: สร้าง site key ที่ [Cloudflare Turnstile](https://www.cloudflare.com/products/turnstile/)
   แล้วเปิด **Authentication → Attack Protection → CAPTCHA** ใส่ secret key
5. สร้างบัญชีผู้ดูแล: **Authentication → Users → Add user** (อีเมล + รหัสผ่าน) แล้วรันใน SQL Editor:
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'อีเมลผู้ดูแล';
   ```
6. แก้ `src/config.js`:
   ```js
   supabaseUrl: 'https://xxxx.supabase.co',
   supabaseAnonKey: 'คีย์ anon (public)',   // ห้ามใช้ service_role key เด็ดขาด
   turnstileSiteKey: 'site key จากข้อ 4',
   ```
7. (ไม่บังคับ) เปิด extension **pg_cron** แล้วรันคำสั่งท้ายไฟล์ migration เพื่อปิดรายงานหมดอายุอัตโนมัติ

## ขึ้นเว็บ (Hostinger หรือ Cloudflare Pages)

**ขึ้นระบบจริงแบบอัตโนมัติ (GitHub Pages + Supabase + GitHub Actions; Hostinger เป็นทางเลือก): ดูคู่มือทีละขั้นที่ [docs/DEPLOY.md](docs/DEPLOY.md)**

อัปโหลดเองแบบครั้งเดียว:

```bash
python3 tools/build_web.py      # สร้าง dist/flood-map-web.zip
```

- **Hostinger:** hPanel → Websites → จัดการ → File Manager → เปิด `public_html` (หรือสร้างโฟลเดอร์ย่อย เช่น `flood`) → Upload ไฟล์ zip → คลิกขวา Extract → เปิด SSL ในหน้า Security ถ้ายังไม่ได้เปิด
- **Cloudflare Pages:** Workers & Pages → Create → Pages → Upload assets → เลือกโฟลเดอร์ที่แตก zip แล้ว
- ในไฟล์มี `.htaccess` (บังคับ HTTPS, ให้เบราว์เซอร์เห็นไฟล์ใหม่ทันทีหลังอัปเดต) และ `_headers` สำหรับ Cloudflare
- **ถ้ายังไม่ได้ตั้งค่า Supabase ระบบจะเป็นโหมดทดลอง** — หน้าเว็บจะมีแถบเตือนสีเหลืองว่ารายงานยังไม่ส่งถึงเจ้าหน้าที่ อย่าประกาศให้ประชาชนใช้จริงจนกว่าจะต่อ Supabase

## ความปลอดภัยและความเป็นส่วนตัว

- สิทธิ์ทั้งหมดบังคับที่ฐานข้อมูล (RLS) คนทั่วไปเห็นเฉพาะรายงานที่ยืนยันแล้ว เปลี่ยนสถานะได้เฉพาะผู้ดูแล
- รูปถูกย่อในเครื่องผู้แจ้ง และ **ลบข้อมูลที่ฝังในรูป (EXIF/GPS) ก่อนอัปโหลด**
- รูปที่ยังไม่ผ่านการตรวจเห็นได้เฉพาะผู้แจ้งและผู้ดูแล รูปของรายงานที่ถูกปฏิเสธจะถูกลบ
- ผู้แจ้งน้ำท่วมไม่ต้องให้ข้อมูลส่วนตัว (ใช้รหัสสุ่มต่อเครื่อง) ส่วนเบอร์โทรของผู้ขอความช่วยเหลือเก็บในตารางแยก `help_contacts` ที่อ่านได้เฉพาะเจ้าตัวและเจ้าหน้าที่ ถูกลบเมื่อคำขอถูกปฏิเสธ และควรตั้งงานลบอัตโนมัติ 30 วันหลังปิดคำขอ (คำสั่งอยู่ท้ายไฟล์ SQL)
- **แจ้งได้ไม่จำกัดจำนวนครั้ง** ผู้ดูแลเป็นคนคัดกรองเอง (มีตัวช่วยจับรายงานซ้ำ/ใกล้กัน/รูปซ้ำ) และรับเฉพาะจุดในพื้นที่ให้บริการ

## เปลี่ยนพื้นที่ให้บริการ

แก้ให้ตรงกัน 3 ที่: `CONFIG.map.area` / `CONFIG.map.bounds` ใน `src/config.js`, ช่วงพิกัดในฟังก์ชัน `in_area()` ในไฟล์ SQL และ `BOUNDS` ใน `tools/bake_osm.py` (แล้วรันสคริปต์ใหม่) ถ้าต้องการเส้นขอบใหม่ให้เปลี่ยน `data/area.geojson` ด้วย
